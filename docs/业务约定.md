# 业务约定

tests.path_id 与 test_id 标识一次端到端实测，result 为 pass、fail、timeout、not_run。read/control 不互推。compatibility 仅对列出的 firmware/protocol 范围有效。line_requirements 的 required_path_group 是可替代路径组，组内至少一条完整路径可用；同线多个组都必须满足。gateways.max_devices 是同时上限，confirmed_allocations 先占容量。quotes.region、valid_to 和 delivery_before 均须满足 plan。

所有记录为本地合成资料；缺失值为 JSON null。资料中的候选操作不是已确认操作。编号仅标识对象，不携带优先级。历史截点以当时已获知事实判断，不以后来的更正冒充当时已知。
