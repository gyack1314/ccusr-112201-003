# 资料目录

所有 JSON Lines 文件使用 UTF-8 编码。data/catalog.json 保存字段、行数、主键及校验和；原始资料不含分析结果。

## devices

文件 data/devices.jsonl；24 条；主键 device_id。字段：device_id, kind, firmware, vendor。

## paths

文件 data/paths.jsonl；16 条；主键 path_id。字段：path_id, sensor_id, gateway_id, app_id, protocol, capability。

## tests

文件 data/tests.jsonl；160 条；主键 test_id。字段：test_id, path_id, result, tested_at, capability, firmware, condition。

## compatibility

文件 data/compatibility.jsonl；16 条；主键 compatibility_id。字段：compatibility_id, path_id, firmware, protocol, valid_from, valid_to。

## gateways

文件 data/gateways.jsonl；8 条；主键 gateway_id。字段：gateway_id, max_devices, region。

## line_requirements

文件 data/line_requirements.jsonl；12 条；主键 requirement_id。字段：requirement_id, line_id, required_path_group, capability, devices_needed。

## quotes

文件 data/quotes.jsonl；24 条；主键 quote_id。字段：quote_id, vendor, path_id, region, valid_to, delivery_before, price。

## confirmed_allocations

文件 data/confirmed_allocations.jsonl；1 条；主键 allocation_id。字段：allocation_id, line_id, gateway_id, devices, start, end。

## plans

文件 data/plans.jsonl；6 条；主键 plan_id。字段：plan_id, line_id, region, start, end, status。

## withdrawals

文件 data/withdrawals.jsonl；1 条；主键 withdrawal_id。字段：withdrawal_id, test_id, issued_at。
